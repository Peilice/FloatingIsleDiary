# 浮島日記 Floating Isle Diary（灰盒，M1～M6＋家長端）

> 存檔與快取的內部代號 `cloudisland-v1` 是舊的暫定名，刻意不改，避免玩家存檔消失。

草地、天氣、種植、1 位居民、圖鑑。純網頁，Phaser 3，離線可玩（PWA）。

## 在電腦上玩

在這個資料夾開終端機：

```
python -m http.server 8080 --bind 0.0.0.0
```

瀏覽器開 `http://localhost:8080/`

## 在平板上玩

1. 平板和電腦連同一個 Wi-Fi
2. 平板瀏覽器開 `http://<電腦的區域網路 IP>:8080/`（IP 用 `ipconfig` 查）
3. 第一次連不上時，檢查 Windows 防火牆是否允許 Python 的私人網路連線
4. 想像 App 一樣開啟：Safari 選「加入主畫面」，Chrome 選「安裝應用程式」。
   注意：離線快取與安裝需要 https 或 localhost，區網 http 連線只能當一般網頁玩

## 偵錯

| 方式 | 說明 |
|---|---|
| `?fast=1` | 網址加上去，時間 4 倍速；`?fast=20` 為 20 倍 |
| `?save=名稱` | 使用另一個存檔（測試用，不會動到正式進度） |
| `?unlock=1` | 直接開放所有區域 |
| `?bot=1` | 亂點機器人（忽略測試），用另一個存檔；Console 輸入 `__ci.report()` 看各機制第一次就對的比例 |
| 清除存檔 | 網址加上 `?reset=1`（不要用 `localStorage.clear()`，舊頁面關閉時會把存檔寫回去） |
| 查看狀態 | Console 輸入 `__ci.state` |

## 目前已有

- 裝飾：圖鑑越完整，能用星砂買的裝飾越多（花圃、籬笆、長椅、路燈、旗子、噴水池）
- 地圖（主畫面）：按開始後先選要去哪座島；遊戲中按上方「地圖」可以回來

- 6 塊地、6 種植物（紅蘿蔔、豆子、玫瑰；玉米、馬鈴薯、葡萄要用星砂買種子），各有不同光照需求，左排被樹蔭擋住一半的光
- 工具：種子袋（選種子、買新種子）、澆水壺、鏟子（挖掉沒成熟的植物，種子回到種子袋）
- 4 種天氣（晴、多雲、雨、風），每天隨機，影響光照與水分；第 2 天起每天早上要選出今天的天氣
- 缺水和缺光會在地塊旁冒出圖示提示，植物不會死
- 兔子用英文提出願望（排程器挑選，只要種過的作物）；從背包選一樣東西再點兔子，選錯會搖頭、不扣東西
- 每天結束寫一句日記（3 選 1 填空），日記本可以翻回前面
- Pip 的 6 步引導，檢查「是否完成」，種哪一種都可以
- 圖鑑 14 項（植物、天氣、動物），可翻頁
- 池塘森林（完成 5 個願望後解鎖）：幫來訪的動物蓋對的棲地（pond、tree、grass），空地可用星砂擴建到 7 塊，住下來的動物也會提出願望；草叢搖動時點它，聽叫聲選出是誰
- 設定（齒輪）：中文字幕開關、聲音開關
- 市集（森林住進 2 隻動物後開放）：居民來買水果（`Three red apples, please.`）或問天氣該穿什麼（`It is rainy. What do I need?`）
- 海灘（收成 5 次、圖鑑 5 項後開放，在草地左邊）：四個實驗站：甜茶（熱水、冷水與溶解）、紫色花汁（酸、甜、苦變色）、磁鐵（先猜再驗證，不是所有金屬都會被吸）、挖挖看（石頭、沙子、泥巴）
- 洞穴（圖鑑 12 項後開放，在海灘左邊）：找植物（暗處聽 left/right/near/far 指令移燈）、月亮（月相排序）、推與拉（看圖分辨 push/pull）
- 設施修理：草地水井、森林小橋、海灘碼頭、洞穴樓梯，花星砂並選對材料（wood、stone…）修好，各有小好處
- 燈塔（修好 3 個設施後開放，在洞穴左邊）：電路（導體與開關，可用檢查模式）、修樂器（找出不振動的那個）、霧中找朋友（看波紋、聽 louder/quieter）
- 防災演練日：每第 7 天，準備防災包、照 Drop/Cover/Hold on 做動作
- 回收（海灘第 5 站）：垃圾分類、找出讓池塘變髒的來源
- 研究島（延伸層，池塘森林右邊）：氣象站（水循環、颱風）、生態研究所（食物鏈、光合作用、拼字）、地質洞窟（音調、化石地層）
- 日曆：上方顯示星期；居民會邀請你某一天去派對，選對那天，到時候就有派對
- 單字提示逐步淡出：圖＋英文＋中文 → 圖＋英文 → 只有英文與語音；只有「3 個以上選項、第一次就對、沒用提示」才算答對
- 自動存檔；M1 存檔會自動轉換

## 已知限制

- 語音暫用瀏覽器的 speechSynthesis，不同平板音質不一，正式版要換預錄音檔
- 美術全是程式畫的幾何圖形，只是占位
- 家長端：按住齒輪 3 秒，答對加法題後可以看遊玩時間、單字紀錄、課綱接觸情形，也能重設進度
