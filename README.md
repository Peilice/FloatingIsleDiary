# 浮島日記 Floating Isle Diary

給國小學生自學用的平板網頁遊戲：在會飄浮的小島上種植物、養動物、迎接天氣，過程中自然接觸課綱內的自然與英文。
看起來像一般遊戲，學習藏在規則裡，沒有考試感。

## 資料夾

| 路徑 | 內容 |
|---|---|
| `game/` | 遊戲本體（Phaser 3，純網頁，可離線）。執行方式見 `game/README.md` |
| `docs/進度紀錄.md` | **接手先讀**：已完成、已定決策、下一步、待確認事項、環境備忘 |
| `docs/機制規劃.md` | **機制的唯一依據**：審查、模擬結果、各模組機制卡、里程碑 |
| `docs/遊戲企劃.md` | 世界觀、美術、技術、風險 |
| `docs/課程對照表.md` | 課綱（自然、英文）條目與單字範圍，分核心層（3～4 年級）與延伸層（5～6 年級） |
| `data/單字清單.csv`、`.json` | 397 個單字（主動 377、被動 20），含模組、層、是否在課綱字彙表內 |
| `tools/sim/` | 數值模擬（Node.js）：植物生長、食物鏈 |

## 快速開始

```
cd game
python -m http.server 8080 --bind 0.0.0.0
```

瀏覽器開 `http://localhost:8080/`，網址加 `?fast=1` 可 4 倍速、`?reset=1` 清除存檔。

## 執行模擬

```
node tools/sim/sim_m1c.js
node tools/sim/sim_food.js
```
