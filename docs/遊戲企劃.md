# 遊戲企劃書（草案 v2）

> **機制以 `機制規劃.md` 為準**，本文件保留世界觀、美術、技術與風險。兩者衝突時，以機制規劃為準。

**名稱：浮島日記（Floating Isle Diary）**
**類型：小島經營 × 圖鑑收集**
**平台：平板瀏覽器（橫向、觸控），可加入主畫面，離線可玩**
**對象：國小四年級，自學**
**核心原則：看起來像一般遊戲，學習藏在規則裡，沒有考試感**

---

## 一、一句話介紹

你在一座會飄浮的荒島上醒來，身邊有一隻會說外國話的小夥伴 Pip。
種植物、養動物、迎接天氣，讓小島變得熱鬧，並把島上遇見的一切收進圖鑑。
每天結束時，你和 Pip 一起寫下當天的**日記**，那是遊戲的自然結束點。

---

## 二、世界與角色

| 角色 | 設定 | 在學習上的功能 |
|---|---|---|
| **玩家** | 被風吹到小島的探險家，可選外觀 | 無 |
| **Pip（小夥伴）** | 一隻小狐狸或小雲朵，只講英文，用動作和表情輔助 | 教學引導，用「做給你看」代替說明 |
| **居民** | 隨小島發展陸續來的動物角色，各有個性 | 提出英文願望，推動任務 |
| **天氣精靈** | 每天帶來不同天氣 | 讓天氣成為會影響玩法的系統 |

**劇情主線（簡單即可）**：小島因為缺乏生命而漂浮不穩，島上的生命愈多，島愈穩，最後降落在大陸邊。每個階段解鎖新區域，圖鑑完成度決定結局。

---

## 三、核心玩法循環

```
觀察天氣和島的狀況
   ↓
種植、放置設施、照顧
   ↓
收成資源（星砂、種子、材料）
   ↓
擴建小島、迎接新居民
   ↓
發現新物種 → 圖鑑解鎖
   ↓（回到頂端，天氣已改變）
```

**一次遊玩約 10～15 分鐘**，有明確的小目標：今天完成 3 個居民願望。

## 四、自然知識如何變成「規則」

玩家看不到「這是自然課」，只會覺得這個遊戲的世界很合理。

| 自然主題 | 遊戲機制（玩家的感受） | 背後的概念 |
|---|---|---|
| 植物生長 | 種子要放在有光和水的位置才會發芽；少了其中一樣，會看到葉子枯黃的提示 | 發芽和生長條件 |
| 植物構造 | 根可以煮湯、莖可以做木材、葉可以泡茶、花吸引蝴蝶、果實給居民吃 | 各部位功能 |
| 動物棲地 | 蓋池塘才會有青蛙，種樹才會有鳥；放錯環境居民會「不開心」並離開 | 棲地與特徵 |
| 動物外形與分類 | 圖鑑可用特徵篩選（會飛、會游、幾隻腳）；觀察頭、軀幹、肢的差異；延伸層可依形態特徵做正式分類 | 動物外部形態（INb-Ⅱ-5）；生物分類（INb-Ⅲ-8，延伸） |
| 食物鏈與生態平衡（延伸） | 草、兔、狐的數量互相影響，某物種太多或太少，島上會出現連鎖變化 | 食物鏈、生態系（INa-Ⅲ-10、INc-Ⅲ-9） |
| 光合作用（延伸） | 遮光與照光的植物對比，觀察生長差異 | INa-Ⅲ-9 |
| 天氣與水 | 下雨裝滿水桶；放著冰塊會融化；冷天池塘結冰才能走過去；溫度計與雨量筒顯示數值 | 水的三態、天氣測量（INc-Ⅱ-6、INd-Ⅱ-7） |
| 水循環（延伸） | 建「集水器」，觀察水從海面蒸發、凝結成雲、降雨，再流回海洋，雨量影響植物生長 | 水循環（INd-Ⅲ-12） |
| 溶解與酸鹼 | 煮糖水、泡茶；用花瓣汁測試食物變色 | 溶解、酸鹼變色（INe-Ⅱ-2～4） |
| 光 | 用鏡子把光導到溫室暗角；障礙物擋光出現影子；夜晚用望遠鏡看月亮盈虧 | 光直線前進與反射、月亮盈虧（INe-Ⅱ-6、INc-Ⅱ-10） |
| 電路 | 修復燈塔：把電池、導線、開關接好；不通就找斷在哪裡 | 通路、導體 |
| 磁鐵 | 用磁鐵在沙灘吸取金屬零件，收集後用來修理設施 | 磁性物質 |
| 聲音 | 敲鐘、撥弦可見振動；隔牆或水下聽到的聲音不同；聽動物叫聲判斷居民需求；延伸層可調音調吸引動物、用隔音牆防治噪音 | 振動與傳播（INe-Ⅱ-5）；音調、樂音與噪音（INe-Ⅲ-6，延伸） |
| 地表與土石 | 挖掘辨認岩石、砂、土；大雨沖走沙地，可築擋牆；延伸層加入礦物、土壤成分、河流改道、挖到化石 | 岩石砂土（INc-Ⅱ-9、INd-Ⅱ-5）；礦物、風化、侵蝕堆積、化石（INc-Ⅲ-11、INd-Ⅲ-8～10，延伸） |
| 地震與防災 | 小島偶爾微震；平時整理防災包、固定家具，震動時帶居民趴下掩護，震後檢查修復設施；延伸層加入颱風、土石流防災 | 地震災害與防震準備（INf-Ⅱ-6）；臺灣主要天然災害（INf-Ⅲ-5，延伸）；板塊、斷層屬國中，不做 |

**設計準則**：玩家失敗時，只能看到「現象」和「線索」，不會出現「答錯了」。例如：種子沒發芽，會看到小太陽圖示冒出來，暗示缺少光。

### 內容分層：核心層與延伸層

| 層 | 對應課綱 | 在遊戲中的位置 |
|---|---|---|
| 核心層 | 第二階段（3～4 年級） | 主線，前期與中期關卡必玩 |
| 延伸層 | 第三階段（5～6 年級） | 核心層完成後解鎖的後期區域與選擇性挑戰，不強迫，孩子想探索再進 |
| 不放入 | 第四階段以上（國中） | 板塊、斷層、地震波等 |

延伸層以「島上的進階區域」呈現，例如氣象站、地質洞窟、生態研究所，讓程度較好的孩子有東西可挖，也方便之後給五、六年級使用。

## 五、英文如何變成「遊戲語言」

不開設「英文課」，英文就是這個世界的語言。

### 1. 出現場合

| 場合 | 例子 |
|---|---|
| 居民願望泡泡 | 氣泡裡有圖片加英文和語音：`I want an apple.` |
| 道具和物種名 | 道具欄、圖鑑的名稱為英文，點一下可聽發音 |
| Pip 的指令 | 帶玩家操作：`Plant the seed.` 同時用手勢示範 |
| 天氣預報 | 每天開始，天氣精靈說 `It is rainy today.` |
| 方位和動作 | 任務要求 `Put the lamp on the left.` |

### 2. 三階段淡出提示

| 階段 | 呈現方式 |
|---|---|
| 初見 | 圖片＋英文＋語音＋中文小字（可關閉） |
| 熟悉 | 圖片＋英文＋語音 |
| 熟練 | 只有英文＋語音，需要玩家自己理解 |

系統自己依玩家表現切換，**玩家不會看到階段名稱**。

### 3. 重複但不單調
- 同一個單字會以不同角色、不同情境再出現（居民、天氣、圖鑑、任務）。
- 一個新字在 3 天內至少自然重現 3 次。

### 4. 不做的事
- 不出現選擇題畫面。
- 核心層不要求拼字：課綱第二階段只要求臨摹抄寫（4-Ⅱ-3）。描字母（例如幫自己的島命名）只作選擇性活動。
- 延伸層加入「拼字挑戰」（4-Ⅲ-3，國小階段 180 個字詞要會拼寫）：用觸控字母方塊拼出物品名稱，不設時間壓力、不扣資源。
- 不因為聽不懂就扣資源。

## 六、小島區域與解鎖

| 順序 | 區域 | 解鎖條件 | 自然重點 | 英文重點 |
|---|---|---|---|---|
| 1 | 草地 | 開局 | 植物生長和構造 | 顏色、食物、植物名 |
| 2 | 海灘 | 完成第一批植物 | 天氣、水的三態、磁鐵、岩石砂土 | 天氣、冷熱、數字 |
| 3 | 池塘森林 | 迎來第一場雨並蓄水 | 動物棲地與外形、溶解與酸鹼 | 動物、動作、身體部位 |
| 4 | 洞穴 | 圖鑑達 20 項 | 光的直線與反射、力與運動 | 方位、大小、遠近 |
| 5 | 山丘燈塔 | 修好 3 個設施 | 電路、聲音、地震防災 | 開關、音量、樂器、防災用語 |
| 延伸 6 | 氣象站 | 完成主線 5 區 | 水循環、天氣圖、颱風 | 天氣與季節進階句型 |
| 延伸 7 | 生態研究所 | 圖鑑達 40 項 | 食物鏈、生態平衡、光合作用 | 拼字挑戰、故事繪本 |
| 延伸 8 | 地質洞窟 | 完成洞穴與燈塔 | 礦物、土壤、侵蝕堆積、化石 | 自我與家人介紹 |

## 七、圖鑑系統

| 項目 | 規劃 |
|---|---|
| 條目數 | 約 60 項：植物 20、動物 24、天氣 8、物質與設備 8 |
| 條目內容 | 圖片、英文名、發音、特徵標籤（自然知識）、一句有趣的事實 |
| 獲得方式 | 以遊戲行動觸發，例如「在下雨天種下蘑菇」才會發現雨林蛙 |
| 稀有度 | 一般、稀有、傳說，稀有物種需要特定條件組合，鼓勵玩家實驗 |
| 篩選 | 依標籤篩選，自然形成分類活動 |
| 完成度 | 影響結局和裝飾道具，不顯示「分數」 |

## 八、進度與獎勵

| 系統 | 說明 |
|---|---|
| 貨幣 | **星砂**：完成居民願望、收成或圖鑑發現時獲得 |
| 擴建 | 用星砂解鎖新地塊和設施 |
| 裝飾 | 圖鑑完成度換取外觀和家具，滿足收集欲 |
| 每日登入 | 每天一份小驚喜，不設連續登入懲罰 |
| 難度 | 不分難度，系統依玩家表現調整提示多寡 |

## 十、美術與音效

| 項目 | 方向 |

## 十一、技術規劃

| 項目 | 方案 |
|---|---|
| 引擎 | **Phaser 3**（HTML5 2D 遊戲框架，觸控支援成熟） |
| 型態 | **PWA**：可加到平板主畫面，離線可用 |
| 存檔 | 瀏覽器本機儲存（IndexedDB），支援多玩家檔 |
| 畫面 | 橫向，自動縮放配合不同平板尺寸 |
| 音訊 | 第一次觸碰後才播放（瀏覽器限制），音檔先預載 |
| 資料驅動 | 物種、願望、單字、任務都放在 JSON 檔，之後新增內容不必改程式 |
| 測試 | 至少在一台 iPad 和一台 Android 平板上實測 |

## 十四、風險與對策

| 風險 | 對策 |
|---|---|
| 做出來仍然像教材 | 每個機制先問「沒有學習目的，它好玩嗎？」不好玩就刪 |
| 自然知識不準確 | 所有概念對照課綱和教科書，製作時請老師或家長審閱 |
| 英文太難被忽略 | 圖片和動作先行，三階段淡出，先讓玩家「看得懂」 |
| 平板效能不足 | 控制動畫數量和圖片大小，早期就用真機測試 |
| 內容量太大做不完 | 以區域為單位分階段，每階段結束都是可玩版本 |
| 孩子沉迷 | 加入「休息一下」提示，每次遊玩有自然結束點 |
