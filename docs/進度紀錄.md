## 1. 專案一句話

**浮島日記 Floating Isle Diary**：給國小學生自學用的平板網頁遊戲，在會飄浮的小島上種植物、養動物、迎接天氣，自然接觸課綱內的自然與英文。看起來像一般遊戲，沒有考試感。

## 5. 已知問題與待確認

| 項目 | 說明 |
|---|---|
| **效能** | 背景視窗量到每格約 24 毫秒，但背景會被降速、數字雜訊大；要在平板實機上量 |
| 交付的忽略測試樣本少 | 機器人每天只收成約 0.4 次，118 天只有 10 次 3 選 1 交付（30%），需要加長測試 |
| 英文課綱版本 | 目前讀的是 105 年草案，要與正式公布版核對條目編號；也看不出字彙表中哪些是最基本 1,200 字（底線標示是用 PDF 偵測推估的，得到約 1,240 個） |
| 自然科學習表現 | 觀察、推論、實驗等探究能力條目還沒讀 |
| 課綱 INg-Ⅲ-4 | 原文被截斷，需核對全文 |
| 年級對應 | 課綱是兩個年級合併規定；每個單元實際落在三、四、五還是六年級，要拿出版社目錄對照（例如影子的規律是否在中年級） |
| 單字清單 | 中文翻譯是我寫的，沒有人審過；主動字 377 個比課綱國小 300 字多 |
| 語音 | 目前用瀏覽器 speechSynthesis 占位；正式版改預錄音檔（真人或 AI 生成尚未決定） |
| Pip 外型 | 小狐狸（現在畫的）或小雲朵，尚未最終決定 |
| 平板實測 | 還沒在真正的平板上試玩，觸控大小與手感未知 |
| 單字產生腳本 | 解析課綱 PDF 的腳本在暫存資料夾，沒有放進倉庫（依賴下載的 PDF） |

## 6. 怎麼繼續

```
cd game
python -m http.server 8080 --bind 0.0.0.0
```

- 瀏覽器開 `http://localhost:8080/`；網址加 `?fast=1` 為 4 倍速（`?fast=20` 為 20 倍）、`?reset=1` 清除存檔、`?bot=1` 亂點機器人（用另一個存檔，Console 輸入 `__ci.report()` 看結果）、`?save=名稱` 用另一個存檔測試、`?unlock=1` 直接開放所有區域
- 平板連同一個 Wi-Fi，開 `http://<電腦 IP>:8080/`（IP 用 `ipconfig` 查）
- 查狀態：Console 輸入 `__ci.state`，場景是 `__ci.scene`
- 模擬：`node tools/sim/sim_m1c.js`、`node tools/sim/sim_food.js`、`node tools/sim/sim_sched.js`
- 規則檢查：`node tools/sim/test_logic.js`

## 7. 環境備忘

| 項目 | 說明 |
|---|---|
| 推送 | 用 git 本身存的憑證可以推送；`gh` 的 `GH_TOKEN` 環境變數是無效的，用 `gh` 指令前要重新登入（`gh auth login`） |
| 換行 | Windows 預設會把 LF 轉 CRLF，提交時會有警告，不影響內容；要消除可加 `.gitattributes` |
| 重置存檔 | 不要用 `localStorage.clear()`，舊頁面關閉時會把存檔寫回；用 `?reset=1` |
| 存檔代號 | 內部 key 與快取名稱是舊暫定名 `cloudisland-v1`，刻意不改，避免玩家存檔消失 |
| 資料夾 | 倉庫在 `E:\國小教材\FloatingIsleDiary` |
| 瀏覽器在背景時 | Chrome 會把畫面降到約 1 fps，自動測試時在 Console 用 `game.step()` 手動推進 |
| M1 存檔備份 | 本機 Chrome 的 localhost:8080 有 `cloudisland-v1-backup-m1`（測試前的 M1 存檔），確認不需要後可刪 |
