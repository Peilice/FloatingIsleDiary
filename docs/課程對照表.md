## 三、遊戲化原則

1. **核心層優先、延伸層自願**：延伸內容不阻擋主線進度，孩子準備好才去碰。
2. **不放國中內容**：板塊、斷層、震央震源等一律不放。
3. **語音靠預錄音檔**：不依賴裝置即時語音合成。
4. **科學詞彙分兩類**：課綱字彙表內的字列為主動練習，不在表內的名詞被動接觸。
5. **自然概念以現象呈現**：不出現測驗畫面，失敗時只給線索。
6. **拼寫只在延伸層**：核心層不要求拼字。
